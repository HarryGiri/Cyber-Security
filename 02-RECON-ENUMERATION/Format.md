# Reconnaissance & Enumeration Format

Use this structure when documenting reconnaissance and enumeration work.

## Assessment Flow

```text
Target
  ↓
Host Discovery
  ↓
Port Discovery
  ↓
Service Identification
  ↓
Version Information
  ↓
Technology Identification
  ↓
Attack Surface Mapping
  ↓
Findings
```

## Documentation

- Target / scope
- Host discovery
- Port scan
- Service enumeration
- Version information
- Technology identification
- Interesting findings
- Next steps
