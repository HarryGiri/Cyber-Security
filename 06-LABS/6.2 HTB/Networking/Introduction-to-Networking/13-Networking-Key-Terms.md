# 13 - Networking Key Terminology

## Purpose

This section provides a compact vocabulary for networking and later security modules.

## Important Terms / Protocols

| Protocol / Term | Acronym | Main Use |
|---|---|---|
| Simple Mail Transfer Protocol | SMTP | Email transfer |
| Network File System | NFS | Remote file access |
| Simple Network Management Protocol | SNMP | Network-device management |
| Network Time Protocol | NTP | Time synchronization |
| Domain Name System | DNS | Name resolution |
| Server Message Block | SMB | File/resource sharing |
| Secure Shell | SSH | Secure remote access |
| Hypertext Transfer Protocol | HTTP | Web communication |
| Hypertext Transfer Protocol Secure | HTTPS | Secure web communication |
| Remote Desktop Protocol | RDP | Remote desktop access |
| Lightweight Directory Access Protocol | LDAP | Directory services |
| Dynamic Host Configuration Protocol | DHCP | IP configuration |
| Internet Control Message Protocol | ICMP | Network control/troubleshooting |
| Internet Group Management Protocol | IGMP | Multicast management |
| Open Shortest Path First | OSPF | Routing |
| Session Initiation Protocol | SIP | VoIP sessions |

## Pentesting Relevance

Knowing protocol names and purposes makes service enumeration more useful. When a scan reports a port, the protocol should immediately suggest what kind of service or attack surface may be present.
