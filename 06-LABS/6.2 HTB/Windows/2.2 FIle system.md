# File System

---

There are five types of Windows file systems:

- FAT12
- FAT16
- FAT32
- NTFS
- exFAT

FAT12 and FAT16 are no longer commonly used on modern Windows operating systems.

This training covers FAT32 and exFAT, with the main focus on **NTFS**.

---

## FAT32

**FAT32 (File Allocation Table)** is widely used across many storage devices such as USB memory sticks and SD cards. It can also be used to format hard drives.

The `32` in FAT32 refers to the fact that it uses 32 bits of data for identifying data clusters on a storage device.

### Pros of FAT32

- **Device compatibility** → Works with computers, digital cameras, gaming consoles, smartphones, tablets, and more.
- **Operating system cross-compatibility** → Supported by Windows, macOS, and Linux.

### Cons of FAT32

- Maximum file size is **4 GB**.
- No built-in data protection or file compression features.
- Third-party tools are required for file encryption.

---

## NTFS

**NTFS (New Technology File System)** has been the default Windows file system since Windows NT 3.1.

In addition to addressing many limitations of FAT32, NTFS provides better support for metadata and improved performance through better data structuring.

### Pros of NTFS

- Reliable and can restore file system consistency after system failures or power loss.
- Provides granular permissions for files and folders.
- Supports very large partitions.
- Includes **journaling**, meaning file modifications such as additions, modifications, and deletions are logged.

### Cons of NTFS

- Most mobile devices do not support NTFS natively.
- Older media devices such as TVs and digital cameras may not support NTFS storage devices.

# Integrity Control Access Control List (`icacls`)

NTFS permissions on files and folders can be managed through the Windows File Explorer GUI under the **Security** tab.

Windows also provides the `icacls` command-line utility, which allows granular management of NTFS permissions.

---

## View NTFS Permissions

Permissions for a specific directory can be viewed using `icacls`.

```cmd
C:\htb> icacls C:\Windows
```

# Permissions

The NTFS file system has many basic and advanced permissions.

| Permission Type | Description |
|---|---|
| Full Control | Allows reading, writing, changing, and deleting files/folders. |
| Modify | Allows reading, writing, and deleting files/folders. |
| List Folder Contents | Allows viewing and listing folders and subfolders and executing files. Folders only inherit this permission. |
| Read and Execute | Allows viewing and listing files and subfolders and executing files. Files and folders inherit this permission. |
| Write | Allows adding files to folders and subfolders and writing to files. |
| Read | Allows viewing and listing folders and subfolders and viewing file contents. |
| Traverse Folder | Allows or denies the ability to move through folders to reach other files or folders. |

### Permission Inheritance

Files and folders normally inherit NTFS permissions from their parent folder.

This simplifies administration because administrators do not need to explicitly configure permissions for every file and folder.

If permissions need to be configured explicitly, an administrator can disable inheritance for the required files or folders and then set permissions directly.
