# Windows Basics

Windows is one of the most common operating systems encountered during penetration testing.

Important areas to understand:

- Windows versions
- Windows services
- Misconfigurations
- Vulnerabilities
- Remote access technologies
- Active Directory

> **Note:** Active Directory was introduced with Windows 2000.

Older/legacy Windows systems may still exist because of old applications or operational constraints.

## Find Windows Version

Use WMI to retrieve Windows version and build information:

```powershell
Get-WmiObject -Class Win32_OperatingSystem | Select Version, BuildNumber
```
