# Windows Operating System Structure

## Windows File System

- Windows root directory: `C:\`
- Usually contains the Windows installation.

### Important Directories

| Directory | Purpose |
|---|---|
| `Program Files` | 64-bit programs on 64-bit Windows |
| `Program Files (x86)` | 32-bit programs on 64-bit Windows |
| `ProgramData` | Shared application data |
| `Users` | User profiles |
| `Users\Default` | Template for new user profiles |
| `Users\Public` | Files intended for sharing |
| `AppData` | User-specific application data and settings |
| `Windows` | Main Windows OS files |
| `System32` | Core Windows files, DLLs and Windows API |
| `SysWOW64` | Windows components for 32-bit applications |
| `WinSxS` | Windows components, updates and service packs |

---

## AppData

The `AppData` directory contains application-specific data for individual users.

```text
AppData
├── Roaming   → Follows the user profile
├── Local     → Specific to the computer
└── LocalLow  → Lower integrity level
```
