# Prerequisites and Required Skills

## Prerequisites for a Penetration Test

A successful engagement requires more than technical tools.

### 1. Legal Documentation

Important documents may include:

#### Master Services Agreement (MSA)

Defines the overall relationship and contractual terms between the
parties.

#### Statement of Work (SoW)

Defines the specific services and work to be performed.

#### Rules of Engagement (RoE)

Defines how testing will be conducted, including permitted activities
and restrictions.

### 2. Scope and Testing Windows

The scope should identify:

- Authorized targets
- Out-of-scope systems
- Testing limitations
- Approved testing periods

### 3. Technical Information

The tester may need information about:

- Target systems
- Applications
- Network architecture
- Access requirements
- Relevant technologies

### 4. Communication and Emergency Procedures

Define who should be contacted if testing causes unexpected problems or
requires escalation.

### 5. Testing Environment

Understand the environment and any restrictions that affect testing.

### 6. Backup and Recovery

Organizations should consider recovery procedures before potentially
disruptive testing.

### 7. Documentation Requirements

Agree on what evidence and reporting are required.

### 8. Professional Liability Insurance

The material identifies professional liability insurance as a
consideration for professional penetration-testing engagements.

### 9. NDA and Data Handling

Confidentiality agreements and data-handling requirements should be
understood before accessing sensitive information.

## Required Skills

### Core Technical Skills

A penetration tester needs practical understanding of systems, networks,
applications, and security technologies.

Important areas include:

- Networking
- Operating systems
- Web applications
- Security tools
- Vulnerability analysis
- Exploitation concepts

### Documentation and Communication

A tester must be able to explain technical findings clearly to both
technical and non-technical stakeholders.

### Problem-Solving and Analytical Thinking

Testing requires:

- Asking logical questions
- Connecting findings
- Investigating unexpected behavior
- Understanding attack paths

### Continuous Learning

Security changes continuously, so testers need to keep learning new
technologies, vulnerabilities, tools, and techniques.

### Legal and Ethical Knowledge

Testers must understand authorization, scope, privacy, confidentiality,
and professional responsibilities.

### Soft Skills

Important professional skills include:

- Communication
- Attention to detail
- Time management
- Teamwork
- Professional judgment

## Key Point

Technical skill alone is not enough. Professional penetration testing
combines technical ability, analytical thinking, communication, ethics,
documentation, and continuous learning.
