# Methodologies and Frameworks

A methodology provides structure for conducting penetration tests
consistently.

## PTES — Penetration Testing Execution Standard

PTES provides a structured approach to penetration testing and organizes
the engagement into defined phases.

It is useful for understanding how a test progresses from pre-engagement
activities through reporting.

## NIST SP 800-115

NIST SP 800-115 provides technical guidance for information-security
testing and assessment.

It can help structure activities such as:

- Planning
- Testing
- Analysis
- Reporting

## OWASP Web Security Testing Guide

The OWASP Web Security Testing Guide focuses on web application security
testing.

It is especially relevant when assessing:

- Web applications
- Authentication
- Authorization
- Input handling
- Session management
- Common web vulnerabilities

## MITRE ATT&CK

MITRE ATT&CK provides a knowledge base of adversary tactics and
techniques.

For penetration testing, it can help testers understand:

- Adversary behavior
- Attack techniques
- Potential attack paths
- Post-compromise activity

## Choosing a Methodology

The methodology should match:

- Engagement objectives
- Testing domain
- Scope
- Technology
- Client requirements
- Applicable standards

A web application assessment may rely heavily on OWASP guidance, while a
broader engagement may combine several frameworks.

## Developing a Personal Methodology

A tester can build a repeatable workflow by combining relevant
methodologies with practical experience.

### Practical Development

A useful personal process should help answer:

1.  What is authorized?
2.  What do I know?
3.  What don’t I know?
4.  What should I enumerate next?
5.  What vulnerabilities may exist?
6.  How can they be safely validated?
7.  What is the impact?
8.  What evidence is required?
9.  How should the finding be reported?
10. Does remediation need to be retested?

## Key Takeaway

Frameworks provide structure, but they do not replace reasoning. A good
tester uses methodology as a guide while adapting the process to the
target and engagement.
